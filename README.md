**TalentSphere – Cloud-Native Recruitment Platform** | Java 17, Spring Boot, Spring Cloud, RabbitMQ, Docker, MySQL, PostgreSQL, Zipkin

• Architected and developed a distributed recruitment platform using a microservices architecture to manage job postings, company profiles, and employee reviews.

• Built independent Company, Job, and Review services with RESTful APIs, enabling scalable deployment and seamless service isolation.

• Implemented Service Discovery using Eureka Server and centralized request routing through Spring Cloud Gateway for efficient inter-service communication.

• Integrated RabbitMQ for asynchronous event-driven messaging, improving system reliability and reducing service coupling.

• Enhanced fault tolerance through retry mechanisms and circuit breaker patterns, ensuring high availability during service failures.

• Enabled distributed tracing and observability using Zipkin, allowing end-to-end request monitoring across microservices.

• Containerized services with Docker and configured relational databases (MySQL/PostgreSQL) using Spring Data JPA and Hibernate.

• Designed and tested CRUD APIs supporting company management, job lifecycle management, and review operations while following cloud-native development practices.
